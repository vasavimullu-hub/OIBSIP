# Retail Sales EDA

OIBSIP Data Analytics L1, Task 1.

## Contents

- `Task_1_Retail_Sales_EDA.ipynb`: complete exploratory data analysis notebook.
- `retail_sales.csv`: reproducible retail sales dataset used by the notebook.
- `requirements.txt`: Python packages required to run the notebook.

## Run

1. Install dependencies with `pip install -r requirements.txt`.
2. Open `Task_1_Retail_Sales_EDA.ipynb` in Jupyter Notebook or VS Code.
3. Run all cells from top to bottom.

The notebook reports dataset quality, descriptive statistics, monthly and quarterly performance, customer demographics, product and category performance, correlations, a day-of-week analysis, findings, and business recommendations.
